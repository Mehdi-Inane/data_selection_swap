# Legacy experiments

These files preserve the early CIFAR-10/CIFAR-100 prototypes. They are not part
of the shared experimental protocol and are not imported by the
`data_selection_swap` package. Paths come from `RESULTS_ROOT`, `DATA_DIR`,
and `CIFAR10_ARCHIVE` instead of a particular cluster.

Use the maintained entry points under `scripts/train`, `scripts/select`,
`scripts/analyze`, and `scripts/plot` for new experiments.
